# Simon Co-op

Game trí nhớ 2 người chơi: cùng ghi nhớ chuỗi đèn và bấm xen kẽ nhau.

- **Chơi online**: tạo phòng → gửi link/mã 5 ký tự cho bạn bè (kết nối P2P qua PeerJS/WebRTC, không cần server riêng).
- **Chơi chung một máy**: người 1 dùng `WASD`, người 2 dùng phím mũi tên.
- Kiểu xen kẽ: **từng bước** (luân phiên từng đèn) hoặc **từng lượt** (mỗi lượt một người bấm cả chuỗi).

Toàn bộ game nằm trong `index.html`.
