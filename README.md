# Simon Co-op

Game trí nhớ 2 người chơi: thay phiên nhau lặp lại chuỗi đèn, mỗi lượt một người, chuỗi dài thêm 1 đèn sau mỗi lượt.

- **Chơi online**: tạo phòng → gửi link/mã 5 ký tự cho bạn bè (kết nối P2P qua PeerJS/WebRTC, không cần server riêng).
- **Chơi đơn**: một bảng, kỷ lục riêng.
- **2 người 1 máy**: người 1 dùng `WASD`, người 2 dùng phím mũi tên.

Toàn bộ game nằm trong `index.html`.
